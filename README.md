# bib-file

My master BibTeX database, set up the way the MDO Lab runs `mdolab/bib-file`.

| File | What it is |
|---|---|
| `powers-bibdesk.bib` | **Working database.** Open it in BibDesk and edit only this file. It holds linked PDFs, notes, and dates added. |
| `powers.bib` | **Clean copy** generated by `./clean.sh` (bibtool strips the BibDesk-only fields). This is the file Overleaf reads. |
| `bibdesk2clean.bibtoolrsc` | bibtool config, copied from the MDO Lab repo |
| `clean.sh` | Regenerates `powers.bib` |

## Rules (MDO Lab conventions)
1. **Cite keys:** first author's last name + year + lowercase letter: `Liem2017a`, `Gorodetsky2025a`.
2. **If the paper is already in [mdolab.bib](https://github.com/mdolab/bib-file), copy that entry verbatim**, key included.
3. Otherwise **build the entry by hand to match the house style.** Don't trust BibTeX downloaded from the web.
4. `doi` only, **never `url`**.
5. Separate authors with **`and`**, never commas.
6. **Spell out months in full** (`November`).
7. **Don't brace whole titles.** Do protect acronyms and proper names: `{GPU}`, `{H}all`, `{RANS}`.
8. Add `keywords` (your tags).
9. Anything uncertain gets a `TODO-…` keyword so it's easy to find and fix.

## Using it in a paper
**Local LaTeX (default, the way Martins does it):**
1. In the paper folder, run `lnsbib` once. It creates `powers-link.bib`, a symlink to this file.
2. In the document: `\bibliography{powers-link}`.
3. Keep `powers-link.bib` in the paper's `.gitignore`.
4. **When the paper is submitted:** delete the link, copy `powers.bib` in as `powers-copy.bib`, and switch the `\bibliography` line to it, so the paper compiles the same way forever.

**Overleaf (only for co-written docs where others want it):** Upload → From external URL → the raw GitHub URL of `powers.bib` (the repo must be public for this), or just upload a copy.

## Adding a paper (about 3 min)
1. Check whether it's in `mdolab.bib` (in BibDesk: File → Open, search). If it is, copy it over. If not, create the entry by hand.
2. Drag the PDF onto the entry. BibDesk's AutoFile keeps it in `~/Documents/Research/Papers/`, renamed by cite key.
3. Run `./clean.sh && git commit -am "add Citekey" && git push`.
4. Create `04 Literature/Citekey.md` in the vault.
